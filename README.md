# DENI ISLAM

Суровая мультяшная 3D-игра **строго на двоих**. Один сервер = два игрока: вы играете
**джентльменом**, ваш друг — **гопником**. Вы вдвоём просыпаетесь в одном доме, выходите
на улицу с ходячими жителями, покупаете стволы в магазине «Ствол» и идёте грабить большой
банк. Кассирша жмёт тревогу, охрана бьёт дубинками, приезжает полиция, растут звёзды розыска.
Прятаться можно дома — закрыл дверь, и наряд вас теряет.

Онлайн, сохранения, голосовой чат, мобильные контролы, PWA на iPhone и APK на Android.

---

## 1. Как запустить игру

### Вариант A — iPhone / iPad / любой телефон, без установки (PWA)

1. Откройте ссылку GitHub Pages этого репозитория:
   `https://<ваш-логин>.github.io/54r/`
   (она появляется после первого успешного прогона workflow **«Публикация игры на GitHub Pages»** —
   вкладка *Actions*, или *Settings → Pages*).
2. В Safari нажмите **«Поделиться» → «На экран Домой»**.
3. Игра запускается как обычное приложение, в полном экране, ландшафт.

> На Pages нет Node-сервера, поэтому игра сама уходит в **офлайн-режим**: тот же город,
> банк, магазин и копы, а вторым игроком становится бот-напарник «Саня».
> Чтобы играть вдвоём по-настоящему — поднимите сервер (вариант C) и впишите его адрес
> в игре: **Настройки → Адрес игрового сервера**.

### Вариант B — Android, APK

1. Вкладка **Actions** → workflow **«Сборка APK (Android)»** → последний зелёный запуск.
2. Внизу страницы, блок **Artifacts** → скачайте `DeniIslam-APK`.
3. Распакуйте архив. Внутри:
   * `DeniIslam-release.apk` — основной файл, **≥ 30 МБ** (текстуры 3072², три радиостанции,
     несжатые нативные библиотеки);
   * `DeniIslam-debug.apk` — запасной вариант, ставится на любой телефон без плясок.
4. На телефоне разрешите «Установку из неизвестных источников» и поставьте APK.

Release-сборка подписана debug-ключом GitHub Actions — этого достаточно для установки
на любой Android 6.0+ (API 23+).

### Вариант C — свой сервер (настоящий онлайн на двоих)

```bash
npm install
npm run assets     # сгенерировать текстуры/звук/иконки (≈34 МБ)
npm start          # http://0.0.0.0:8080
```

Оба игрока открывают один и тот же адрес. Сервер авторитетен: урон, деньги, звёзды,
охрана, копы, магазин и сохранения считаются на нём, а не в браузере.

Переменные окружения: `PORT` (по умолчанию 8080), `HOST` (по умолчанию 0.0.0.0).

## 2. Управление

### ПК

| Клавиша | Действие |
| --- | --- |
| `W A S D` | Ходьба |
| `Shift` | Бег (тратит выносливость) |
| `Space` | Прыжок |
| Мышь | Камера (клик по экрану — захват курсора) |
| `ЛКМ` | Выстрел / удар |
| `R` | Перезарядка |
| `E` | Взаимодействие: двери, кровати, шкафы, кучи денег, прилавок, грузовик |
| `E` (удерживать) | Грести деньги — 15 с руками, 30 с с сумкой |
| `1…0` | Выбор предмета в инвентаре |
| `Q` | Сумка: посмотреть/положить/забрать |
| `Tab` или `I` | Инвентарь |
| `M` | Магазин (у прилавка) |
| `Esc` | Пауза / меню |
| `V` | Микрофон вкл/выкл |

### Телефон

* **Левая половина экрана** — виртуальный джойстик (появляется там, где коснулись).
* **Правая половина** — камера свайпом + кнопки: огонь, перезарядка, бег, взаимодействие.
* Полоски **здоровья** и **выносливости**, счётчик **денег** и **звёзд розыска** — в HUD.
* Маленькая кнопка **перезарядки** рядом с огнём.
* **Долгое нажатие** на куче денег — грести (кольцо прогресса вокруг пальца).
* Инвентарь — маленькие ячейки внизу экрана; **кулаки в инвентаре всегда**.
* Если патронов нет — тост **«Купите патроны»** и сухой щелчок.

## 3. Механики

**Дом.** Две кровати, два шкафа (по 15 ячеек), дверь на улицу. Шкафы и баланс
сохраняются между сессиями. Смерть = потеря всего инвентаря, респаун на своей кровати.

**Жители.** По городу ходят обычные, пожилые и «плохие» жители — смотрят на вас,
комментируют, при выстрелах разбегаются. «Плохие» могут полезть в драку.

**Подработка.** Время от времени у дороги встаёт грузовик: NPC просит помочь донести
ящики. Оплата каждый раз разная — то копейки, то прилично.

**Оружейный магазин «Ствол».** Продавец, каталог с моделью/ценой/описанием, витрина
с реалистичными моделями. Есть дробовик, АК, М4, MP5, Glock, Desert Eagle, дубинка,
труба, **сумка для денег** и аптечки. Патроны покупаются отдельно и стоят дёшево.

**Банк.** Кассирша, двое охранников с дубинками (со спины не видят — но обернутся),
кучи денег в хранилище и на стойке. Достали оружие на глазах — кассирша жмёт тревогу,
сирена, растут звёзды, едет полиция.

**Розыск.** Звёзды растут за преступления и убийства. Полиция преследует **обоих**
игроков, стреляет тем чаще, чем больше звёзд. Ушли с места преступления и спрятались
(дом + закрытая дверь) — звёзды медленно гаснут, наряд уезжает.

**Деньги.** Руками: 15 секунд на пачку, максимум 5 пачек в инвентаре, затем в инвентаре
выбираете пачку → **«перечислить в баланс»** (сумма случайная). С сумкой: 30 секунд
анимированного сбора, деньги уходят в сумку; сумку можно **«посмотреть»** — вывести
часть или всё. Баланс виден в HUD рядом с HP и выносливостью.

**Голосовой чат.** При каждом входе в игру запрашивается микрофон. Разрешили — голос
работает всю сессию (WebRTC P2P, сигнализация через WebSocket), выключается только
выходом из игры или кнопкой `V`.

**Дружественного огня между двумя игроками нет.**

## 4. Устройство проекта

```
public/                     сайт и клиент (это же содержимое APK и GitHub Pages)
  index.html                весь интерфейс: меню, HUD, панели, тач-контролы
  css/style.css             тёмная индустриальная тема
  js/main.js                игровой класс: three.js, ввод, камера, HUD, сеть
  js/world.js               город, дом, банк, магазин, жители, трафик, LOD и склейка статики
  js/chars.js               джентльмен, гопник, жители, копы, охрана, кассирша, продавец + анимации
  js/models.js              процедурные текстуры и библиотека 3D-моделей
  js/audio.js               звук: ambience, музыка меню, три радиостанции, сирена
  js/net.js                 WebSocket + WebRTC (голос)
  js/localroom.js           офлайн-режим: та же комната в браузере + бот «Саня»
  js/util.js                DOM, localStorage, тосты, адрес сервера
  shared/protocol.js        ОБЩИЙ код клиента и сервера: константы, коллизии, LOS, сид-рандом
  server/room.js            авторитетная комната (используется и сервером, и офлайн-режимом)
  vendor/three/             three.js r187 (локально, без CDN)
  assets/                   ≈34 МБ: текстуры 3072²/2048²/1024², WAV-звук, иконки
  manifest.webmanifest      PWA (полный экран, ландшафт, иконки, шорткат «Играть»)
  sw.js                     кэш для установки на главный экран и офлайн-запуска
server/server.js            Node + ws: статика, /api/health, /api/save, /api/wipe, комната
tools/generate-assets.js    генератор ассетов (без внешних зависимостей)
tools/fetch-three.js        копирует/скачивает three.js при установке
tools/smoke-test.mjs        тест игровой логики (комната, копы, деньги, смерть, шкаф, работа)
tools/render-test.mjs       тест рендера: настоящий three.js, мир, персонажи, бюджет draw call
tools/boot-test.mjs         тест загрузки клиента: main.js целиком на DOM/WebGL-стабах
tools/patch-android-gradle.py  патч build.gradle под сборку APK в CI
capacitor.config.json       упаковка клиента в Android-приложение
.github/workflows/          Pages-деплой и сборка APK
```

Архитектурный принцип: **одна и та же логика комнаты** (`public/server/room.js`) работает
и на Node-сервере, и в браузере в офлайн-режиме. Поэтому офлайн-игра — не урезанная
демо-версия, а та же игра с ботом вместо второго игрока.

## 5. Проверки

```bash
npm test          # все три проверки
npm run test:logic    # логика: слоты, копы, розыск, укрытие, деньги, сумка, шкаф, работа, смерть
npm run test:render   # рендер: мир, персонажи, анимации, двери, интерактивы, бюджет draw call
npm run test:boot     # клиент: main.js грузится и boot() отрабатывает без ошибок
```

Что уже ловят тесты:

* полиция реально спавнится, догоняет и убивает при 3★ (≈35 с бездействия);
* укрытие дома с закрытой дверью: урона нет, розыск снимается за ~20–30 с, наряд уезжает;
* закрытая дверь физически не пускает никого (в том числе копов), открытая — пускает;
* кассирша и охрана видят вход в хранилище → тревога срабатывает;
* дружелюбный огонь между игроками отсутствует;
* смерть забирает весь инвентарь, респаун на кровати со снятым розыском;
* бюджет draw call: улица ≈210, дом ≈145, хранилище ≈310 (иначе на телефоне лаги).

## 6. Производительность

* Статика города, дорог и зданий **склеена в чанки** по материалу: ~2250 мешей → ~270.
* Крыши и двери 57 городских зданий — `InstancedMesh` (3 draw call вместо 114).
* Карта теней **ездит за игроком** (60×60 м) вместо того чтобы накрывать весь город.
* Жители: дальше 16 м переключаются на 4-мешевый LOD, дальше 42 м не рисуются вовсе.
* Дальние машины трафика скрываются.
* Текстуры подтягиваются с диска поверх процедурных уже после старта — вход в игру мгновенный.

## 7. Сборка вручную

```bash
# APK (нужны Java 21 и Android SDK)
npm install
npm run assets
npx cap add android      # один раз
npm run android:apk      # release + debug в android/app/build/outputs/apk/

# ассеты заново (если меняли генератор)
npm run assets
TEX_SIZE_HI=2048 npm run assets      # текстуры поменьше, если нужен лёгкий пакет
```

CI делает то же самое автоматически: при каждом пуше собирает APK и при пуше в `main`
публикует игру на GitHub Pages.
